This project builds an end-to-end Formula 1 data pipeline using data from Jolpica. The workflow downloads the data as a ZIP archive containing CSV files, loads it into a SQLite database, and publishes the tables to Databricks for analysis and visualisation. Insights from that analysis inform the dbt transformations and documentation. A summary view makes the transformed data and results easier to explore. The workflow then retrieves the dashboard created in Databricks and publishes it alongside the dbt documentation on GitHub Pages.

The database produced here serves one primary consumer: the companion Formula 1 analytics project, where it powers exploratory data analysis and the GOAT (greatest-of-all-time) modelling. Working with the raw export quickly surfaced a number of data-quality issues — nationality retrojection, missing fastest-lap coverage before 1958, and several historical quirks worth verifying rather than "fixing" — which are documented in detail in the data-quality review. Rather than patching them privately, this project handles them openly in the transformation layer.

If Jolpica addresses these issues at the source in the future, this pipeline remains useful: its role would shift from correcting the data to providing convenience views — season-scoped nationality resolution, flat summary tables, derived attributes — that make the database immediately usable for analysis without reimplementing the join logic in every query.
